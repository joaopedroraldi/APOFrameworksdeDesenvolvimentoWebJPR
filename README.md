# Livraria JPR

Sistema web de cadastro de livros e clientes, feito com Laravel para a disciplina **Frameworks de Desenvolvimento Web** (UNIPAR EAD).

**Online:** https://ralditech.com.br/APO%20-%20Frameworks%20de%20Desenvolvimento%20Web%20-%20JPR/
(Eu sei que o caminho é horroroso, com espaços(APO - Frameworks de Desenvolvimento Web - JPR), mas pra provar que eu consigo fazer, está aí.)

## Como se cadastrar?
Acesse o link, vá no cadastro e digite o RA do aluno corretamente.

## Funcionalidades

- Login, logout e cadastro de usuário
- Dashboard com o total de clientes, livros e usuários
- CRUD de livros, clientes e usuários
- Listagens com DataTables (busca, ordenação e paginação)
- Visualização dos dados em popup
- Alertas com SweetAlert2
- Layout responsivo

## Tecnologias

- PHP 8.4 e Laravel 13
- MySQL com Eloquent ORM
- Bootstrap 3.4.1 (eu sei que o layout ficou antigo, mas gosto dessa biblioteca)
- Font Awesome 4.7
- DataTables
- SweetAlert2
- jQuery e jQuery Mask
